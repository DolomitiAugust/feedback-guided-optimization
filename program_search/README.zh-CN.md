# 通过评估反馈搜索圆装填程序

[English](README.md) / [简体中文](README.zh-CN.md)

目标是在边长为 1 的正方形内放入恰好 26 个互不重叠的圆，使半径总和尽可能大。程序输出圆心二维坐标与半径；评估器先检查数量、有限值、边界和圆间距离，再计算分数。圆面积不是本实验的优化目标。

选中的大模型生成程序尝试多个确定性初始布局，再使用 SLSQP 联合调整圆心和半径。固定圆心后，各圆半径之间的限制是线性的，可以用线性规划重新分配半径。这不证明整体布局达到全局最优。

## 结果应如何理解

在线记录共七个提案，其中五个完成有效评估，一个实现失败，一个尚未完成评估。在线最佳半径总和为 **2.62001380699489**，来自初始化阶段的候选 `4705b8e92e1b`。第一代子代没有超过这个最好值。任务由操作者手动停止，因此不能声称自动完成全部预算、收敛或找到最优解。

把相同候选程序在本地独立执行，得到 **2.6206092130170973**。该记录使用 Python 3.14.2、NumPy 2.4.4、SciPy 1.17.1，与在线记录不同。程序和库的数值差异可能造成结果变化，但原因没有被单独检验。不能用本地较高分数代替在线分数。

## 代码与运行

`solve.py` 是导出的最佳候选，直接运行只做 CPU 数值优化，不调用模型服务。命令与依赖见 [英文说明](README.md#run-and-check)。`config.yaml` 保留历史搜索配置，凭据为空，需要兼容的平台环境，不能单独完成在线搜索。`upstream/` 保存官方初始程序、评估器与 BSD 许可证，作者和来源必须保留。

`python tests/test_search.py` 检查保存的数据，不重新搜索；它逐一核查 26 个圆和全部圆对，以及在线最佳值确实发生在初始化阶段。

`python program_search/plot_publication_figures.py` 从原始保存数值重画搜索进度和圆装填图。所有圆心与半径保持原值，坐标轴等比例。在线平台没有导出在线最佳值对应的原始圆位置，因此图里的最佳程序布局明确属于本地独立重现。
